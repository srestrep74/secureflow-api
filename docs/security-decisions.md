# Security Decisions

**Status: Phase 0 approved on 2026-11-15; later implementation remains phase-gated.**

Recommend Argon2id, RS256, five-minute access JWT, online security and session state, opaque refresh rotation, explicit HTTPS transport and deny-by-default authorization. PostgreSQL unavailability fails closed. All decisions remain Proposed.

See the [consolidated Phase 0 design](phase-0-design.md) for the complete contract, trade-offs and approval gate.
